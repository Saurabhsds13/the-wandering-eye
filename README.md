# The Wandering Eye

A minimal travel, street and portrait photography portfolio.

## Run locally
Open `index.html` in a browser.

## Deploy
Push the repository to GitHub on the `main` branch, then enable GitHub Pages using **GitHub Actions** as the source. The included workflow deploys the site automatically.

## Before publishing
Replace:
- `hello@example.com` in `index.html`
- the Instagram `href="#"` in `index.html`
- placeholder/temporary category labels as your collection grows
